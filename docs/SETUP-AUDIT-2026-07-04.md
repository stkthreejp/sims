## 3. Batch 1 — fail-open money & identity (before bind tests T7–T9)

The dominant defect class: **setup-driven money/numbering lookups fail open** instead of erroring. Sweep rule to adopt: any lookup that feeds premium, commission, tax, or policy identity must fail closed or emit a blocking warning.

- **A1.1 Commission fail-open** (B2=W6=W16, UI9, E7): missing/unmatchable commission schedules default to **0%** at quote and bind (`QuoteService.cs:207-209` `?? 0`) → SMM remits 100% to London, agent accrues nothing, silently. Unscoped commission paths skip `Enum.TryParse` and store free-string LOBs (a row keyed "GL" never matches); the agent-commission picker offers 9 deprecated LOBs; label maps omit the 3 real active LOBs. Fix: validate LOB on both scope paths; `COMMISSION_SCHEDULE_MISSING` block (or explicit 0-rate row — see Q2) at bind; frontend `ACTIVE_LOBS`.
- **A1.2 Policy-number fail-open** (B4=W7=D3): no matching assignment → silent legacy `POL-YYYY-#####` on a Lloyd's policy; `WritingCompanyId` is a phantom column (no entity, no FK) that **silently disables** any assignment that sets it; sequence delete is unguarded (referencing assignments vanish from admin GETs via filtered-include INNER JOINs, then binds fall back to legacy — and the assignments list endpoint 500s); `NextNumber` can be rewound below issued values. Fix: fail closed on program-scoped binds; drop/validate `WritingCompanyId`; guard sequence delete; `NextNumber ≥ max(usage)+1`.
- **A1.3 Fee-engine config traps** (W8, E3 ✓ PercentOfNet, B6=W9=D10): `PercentOfNet` stored but never read → %-of-net fees compute on gross ✓; `LicenseType`/`City` scope dimensions can never match (context always null) — scoping the SL tax rule to "Non-Admitted" silently removes SL tax from all invoices; `OnlyAppliesToIssuanceState` is a logical no-op; `AppliesToFlatCancellations` actually means "ONLY on flat cancellations" (checking it removes the fee from every normal invoice); unknown `CalcType` → **$0 fee silently**; `FeeCategory=="Tax"` is case-sensitive; FKs (fee definition, ledger account) unvalidated → 500s; state-taxability stores raw codes that never match. Fix: whitelist CalcType/FeeCategory (+ CHECK constraints), validate FKs, hide or implement each dead toggle, normalize taxability states. Also UI8: taxability modal can silently wipe config when a definition has no versions; `ledgerAccountId: 0` posts.
- **A1.4 Bind guards** ✓ (M3 verified, W5, W12): the only status guard at bind is ALREADY_BOUND — **a Declined quote binds via API**; the bind modal lets users shift effective dates and binds the stale rated premium without re-rate; nothing ever sets `QuoteStatus.Expired`; bind never re-validates the program path for the (possibly new) effective date; quote LOB is unconstrained by submission LOBs → **the AL non-bindable block is bypassable** (clearance reads submission LOBs, not quote LOB). Fix: status whitelist, `RERATE_REQUIRED` on date change, path re-validation at bind, quote-LOB ∈ submission LOBs.
- **A1.5 Program-less quotes** ✓ (W4=B12=UI3): "No program" is the quote form's default; it bypasses carrier-LOB capability, state eligibility, and the whole Program-SOT spine — and the bound policy **can never appear on any bordereau** (BDX joins `Policy.ProgramId == profile.ProgramConfigurationId`) ✓. Fix pending Q1: require ProgramId (recommended) or block bind when null.
