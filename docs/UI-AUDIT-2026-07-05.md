# SIMS UI Audit — 2026-07-05

> **What this is:** the consolidated result of a 6-lane parallel UI audit, the frontend companion to `SETUP-AUDIT-2026-07-04.md`. Lanes: **G**=design-guide adherence (vs `SIMS-UI-Guide/tokens.css`, the canonical vocabulary), **U**=core underwriting flow, **B**=billing/accounting, **A**=admin/config, **O**=ops/nav/compliance/documents shell, **X**=cross-cutting sweeps (with counts). ~155 raw findings, deduplicated below. Full per-lane detail with all file:line references lives in `docs/ui-audit/LANE-*.md`.
>
> **How to use:** Batches are sequenced for UAT readiness — Batch 0 items either corrupt data or make required workflows impossible and should land before serious lifecycle testing; Batches 1–5 are the "hard to use / doesn't make sense" fixes in priority order; Batches 6–7 are the "doesn't match up" consolidation. §9 is the dead-affordance kill list; §10 maps overlaps with the setup audit (don't double-fix); §11 needs Jeremiah's decisions; §12 has repro recipes.

## 1. Verdict

**The design guide is real, but only skin-deep.** `index.css` mirrors `tokens.css` faithfully and `sd-*` classes are used across ~58 files — the problem is the codebase diverges from *itself*: **3,019 inline `style={{}}` objects** in 70 files re-implement guide components per page; a cluster of ~10 admin pages is written in a foreign Tailwind palette including a second blue (**621 off-palette class occurrences in 38 files**); status pills have **8 competing implementations**; US state lists have **8 divergent copies** (insured pages are missing DC entirely); currency has **27+ local formatters** with 3 conventions. The highest-leverage design work is consolidation, not re-theming. (G-lane verdict, X9, X11, X15)

**Two systemic date bugs actually corrupt data** (X1/X2): every "today" default is computed in UTC (23 sites — after ~7pm ET, binds/issues/receipts get stamped tomorrow), and date-only values are parsed at UTC midnight so they *render* one day early on about half the app (47 sites) while 5 billing pages carry the local fix — the same policy date reads differently page to page.

**The workflow layer has hard dead-ends** on the exact paths UAT will walk: quotes can't be declined/edited/marked quoted (U1), endorsements can't be issued (U2), renewals can't be started (U3), the rating panel blocks Calculate for every non-IM quote (U4), cash application can't post partials (B1), statement reconciliation has no manual-match UI (B2).

**Failure is invisible by convention:** 115 `data = []` defaults vs 13 `isError` checks (a dead API looks like "no invoices"), ~11 mutations with no onError at all, 15 raw-Axios toasts, ~50 fixed "Save failed" strings hiding trigger messages, and blank screens for detail-fetch errors. This is the UI half of the setup audit's A0.2 finding.
